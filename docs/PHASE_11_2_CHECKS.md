## Catalog activation checkpoint (2026-11-19)

The user selected OpenAI/Google chat families plus the 19 image and 12 speech models shown in their screenshots. Official public catalog metadata resolves these to 114 rows (83 chat, 19 image, 12 speech). Prices, voices, endpoint capability descriptors and output/context limits are static data in models.ts with source URLs and a verification date. Eight explicitly retired upstream models stay disabled, including GPT Image 1; previews and announced deprecations are labeled. Configuring only the OpenRouter key enables the remaining 106 rows; no key leaves real rows unavailable and mocks unchanged.

The earlier Google output-token-cap blocker is resolved against the current documented standard speech request: it does not require that passthrough. Provider token limits remain metadata; no guessed character-to-audio-token formula is used. See DECISIONS.md for the conflict, lifecycle sources, application caps and relative cost assumptions.

Acceptance now includes an offline minimal HTTP Models controller with key absent and with dummy key configured, exact chosen-row availability/default assertions, full catalog schema/coercion/price-source tests, fractional image cost rounding, LLM output-cap enforcement and browser checks for real catalog controls without sending generation calls. Paid live-check success remains a manual user-run check with their own credentials; it is not claimed by offline tests. Seedance/Kling and optional Veo remain outside this checkpoint.
